# Sprite

Per ora il gioco usa `icon.svg` come sprite segnaposto (placeholder).

Quando vorrete grafica più bella, un'ottima fonte gratuita e a licenza CC0
(si può usare liberamente, anche per un gioco pubblicato) è
[Kenney.nl](https://kenney.nl/assets), in particolare i pacchetti:

- **Tiny Dungeon** — tileset e personaggi in stile dungeon top-down.
- **Roguelike/RPG Pack** — tileset, personaggi e nemici più dettagliati.

Scaricate il pacchetto scelto e mettete i file `.png` dentro questa
cartella (`game/assets/sprites/`), poi trascinateli sui nodi `Sprite2D` o
`TileMap` in Godot per sostituire il segnaposto.
